## What's Changed

* Fix global keyboard and multi-monitor mouse input on Windows: key events were packed into the wrong INPUT union fields (so `press_key` / `type_text` with `input_method=global` silently did nothing), pointer moves now normalize against the whole virtual desktop, and a 16-byte VARIANT stub that let UI Automation write past its end is now the full 24-byte layout.
* Fix MCP stdio reliability on Windows and Linux: a malformed JSON-RPC frame no longer sends the server into a 100% CPU loop, and Linux `press_key` chords with an invalid key no longer leave modifier keys stuck.
* Fix macOS robustness: coordinate hit-testing no longer divides by the Retina pixel scale twice (auto clicks landed off-target on Retina displays), malformed accessibility values no longer crash the server, and the app-agent unix socket survives peer disconnects and shutdown races.

**Full Changelog**: https://github.com/opensymph/open-computer-use/compare/v1.0.4...v1.0.5
