## What's Changed

* First stable release under the `open-computer-use` name: the same 9 core Computer Use tools on macOS, Windows, and Linux, plus the window2 API (`list_windows`, `get_window`, `get_window_state`, `launch_app`, `activate_window`) on Windows.
* Windows runtime is now a fully native Go executable (in-process UI Automation + Win32 with process-isolated operations), and the Linux runtime talks to AT-SPI2 natively over D-Bus with zero runtime dependencies.
* Ships a ZCode plugin marketplace and a Codex plugin alongside the npm distribution (`npm i -g @opensymph/open-computer-use`).

**Full Changelog**: https://github.com/opensymph/open-computer-use/compare/v0.3.1...v1.0.0
