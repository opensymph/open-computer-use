## What's Changed

* New `capture_display` tool for full-screen capture, plus `doctor --no-ui` for silent permission probing.
* macOS App distribution: CI builds, signs (Developer ID), notarizes and publishes a universal `Open Computer Use.app` (`Open-Computer-Use-macOS.zip` + `SHA256SUMS.txt` + `app-manifest.json`) on every stable release and on-demand via the `release-app` workflow; new `scripts/ocu-app-install.sh` install engine bundled in the App.
* Upstream fixes: agent identity is captured eagerly at launch via inode (not mtime), and `--version` exposes build number and git commit.

**Full Changelog**: https://github.com/opensymph/open-computer-use/compare/v1.2.0...v1.3.0
