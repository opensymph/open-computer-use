## What's Changed

* New `capture_display` tool: full-screen capture via SCScreenshotManager (single call, no snapshot-restore focus stealing). Includes `doctor --no-ui` for silent permission probing.
* macOS App distribution: CI now builds, Developer ID-signs, notarizes and staples a universal `Open Computer Use.app`, published as `Open-Computer-Use-macOS.zip` + `SHA256SUMS.txt` + `app-manifest.json` on every stable release and on-demand via the `release-app` workflow (prerelease tags `app-build-*`).
* New `scripts/ocu-app-install.sh`: the single install engine (staged validation, quarantine handling, atomic swap, `app_backup` contract, rollback, JSON output), bundled in the App's `Contents/Resources`.
* Upstream fixes: agent identity is now captured eagerly at launch via `stat(2)` inode/dev (not mtime), and `call --version` exposes build number and git commit.

**Full Changelog**: https://github.com/opensymph/open-computer-use/compare/v1.2.0...v1.3.0
